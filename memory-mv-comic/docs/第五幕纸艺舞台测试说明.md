# 第五幕 · 纸艺舞台测试（7.5 秒，对应歌曲 30.0–37.5 秒）

## 分层（只做刚性运动）
- 远景「舞台背板」：补图原画；人物身后用同一张画的柔焦版本，不做修补拼接。
- 中景「人物纸卡」：男女主＋花束＋围巾作为一张整体纸卡，外加约 7 px 米白纸边和柔和投影，人物像素原样。
- 前景：飘雪、暖色光斑、纸质花瓣（白边粉色剪纸）、纸艺烟花（白边星形纸卡）。

## 镜头（切点卡鼓点 31.67 / 33.34 / 34.18 / 35.43 秒）
1. 0–1.67：背板像舞台布景一样立起，镜头从亮着灯的商场门面和圣诞树向下摇、拉开，男女主纸卡从下方滑入就位（带回弹）。
2. 1.67–3.34：「终于见面」双人镜头缓推，男主纸卡轻微前倾，呼吸般的起伏。
3. 3.34–4.18：花束与白围巾特写，礼物纸卡向前浮起，纸质花瓣从花束里迸出，背后两朵纸艺烟花弹开。
4. 4.18–5.43：补图 B，她抱着花和围巾含泪笑，纸卡轻轻滑入，三朵纸艺烟花依次在背板与人物之间绽开。
5. 5.43–7.5：镜头推到两人的脸，5.9 秒起纪念卡从下方滑入、倾斜后落定：米白毛边纸、双线金框、烫金 2025.11.15、一道金光扫过、两枚纸玫瑰贴纸弹出。

## 遵守
人物零形变（无网格、无液化、无骨骼）；女主脖子上没有围巾（只用补图 A/B，围巾始终是礼物）；全屏场景，无书桌/地板/书框。
