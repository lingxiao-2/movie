# 缺失补图清单（尽量少）

现有八幕原画可以覆盖全片 30 个镜头中的 28 个。只有第五幕「递花 → 接花」需要原画里没有的新姿势。

## 必需（2 张）
统一要求：16:9 横屏、1672×941 或更大；与第五幕原画同一画风、同一场景（冬夜、灯树暖光、飘雪）、同一机位高度和光线；
男主黑色羽绒服、黑框眼镜、蓬松深棕短发；女主粉色羽绒服、白色毛绒围巾、深棕长发；大束粉色玫瑰（白色包装纸、粉白丝带），白色针织围巾（粉色蝴蝶结、猫咪吊牌）。不要在画面里写任何文字。

### 补图 A｜男主递花（镜头 5c，中景）
构图：男主在画面左侧，身体侧向右，双手把粉玫瑰花束和叠好的白围巾一起向前递出，手臂自然前伸，微笑、略害羞、脸颊微红；女主在画面右侧边缘露出半边（粉色羽绒服、长发），正看着花束。花束位于画面中央偏右。

### 补图 B｜女主接花后的双人镜头（镜头 5e，中景）
构图：女主在画面右侧，双手把粉玫瑰花束抱在胸前，白围巾已经围在她脖子上（或搭在花束上），含泪但笑得很开心；男主在画面左侧，看着她温柔地笑，一只手轻轻放在她手背上或花束边。两人距离比原第五幕更近。
