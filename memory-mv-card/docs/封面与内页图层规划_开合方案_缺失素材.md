## 3. 开合动画方案（约 5 秒，卡音乐开头的鼓点 0.09 / 0.56 / 1.00 / 1.42 / 1.86 / 2.28 / 2.72 / 3.11 / 3.55 / 3.97 / 4.41 / 4.83 s）
1. 0–1.0 s **礼物出现**：封面原图从暗处显现，缓推；蝴蝶结、双猫吊饰、封蜡依次扫过一道柔和高光（叠加光层，原图不变）。
2. 1.0–2.0 s **解开礼物**：丝带沿卡面横穿方向向两侧滑出画面、蝴蝶结松开（用补图 2 的独立丝带层平移/旋转，或用补图的「松开」状态切换）；封蜡轻轻弹起、旋转离开。
3. 2.0–3.1 s **贺卡打开**：封面作为一整块硬卡，沿左侧折线向镜头翻开（2.5D 透视旋转，卡面本身不拉伸、标题完整）；
   翻开过程中有纸张厚度边、折痕高光和投在内页上的移动阴影。不把标题劈成两半（遵照你划掉的右上格）。
4. 3.1–4.4 s **立体内页升起**：按鼓点依次立起——玫瑰丛 → 情侣立牌 → 双猫 → 摩托＋头盔 → 铭牌最后落定（每层沿底边铰链立起，带轻微回弹和接地阴影，前后遮挡正确）。
5. 4.4–5.5 s **进入第一幕**：镜头推进内页中央、景深收窄；中央立牌后方的夜空渐变为第一幕夜景，
   用参考图右下格（两部手机）作为桥接画面，再以水彩晕染过渡到第一幕原画全景——无黑屏、无闪白。

技术：全部为刚性图层（平移/旋转/整体缩放/透视翻转硬卡）、视差、光影与粒子；不做网格形变、不做人物拉扯。
