# 《把回忆拼好给你》立体纸艺动画规范（Remotion 接入版）v1

适用范围：整支 MV 后续所有页面，包括开场至第四幕的重做，以及第五、六、八幕。
本规范只约束动画做法，不改变已确认的剧情、日期、原画和歌词时间轴。

---

## 0. 总原则

- **画面主体只用你已确认的原画和高清透明 PNG。** 代码只负责：
  - 摆放、折起、翻页这类刚体运动；
  - 光影：阴影、厚度边、环境光。
- **不生成新画面，不重绘人物，不变形人物。**

## 1. 镜头

1. **相机固定。** 每一页从第一帧到最后一帧都显示完整页面（1920×1080 对应整页）。
   - 禁止：Ken Burns、推、拉、摇、移、局部放大、自动特写、裁切静态图做「近景」。
   - 允许整画面变化的只有两种：
     - 翻页本身；
     - 开场封面已确认的缓慢靠近（约 9%）。
2. **「动」只能来自独立图层的刚体运动和光效：**
   - 立牌折起、收回、平移、小角度摆动；
   - 纸页翻落；
   - 雪、光斑、灯光呼吸、花瓣。
3. **任何时刻，画面中至少要有一个元素在动。**
   - 质检时用冻结检测：不允许出现 ≥ 1.0 s 的静止段。
   - 已确认需要停留的定格例外，比如结尾字幕停留。

## 2. 纸雕立牌：底部铰链

1. **每个立牌是一张完整的刚体卡片。** 它有一条平直的底边，就是铰链线。
   - 动画只能绕这条底边旋转，即 CSS `rotateX`，旋转原点在底边中点（`transform-origin: 50% 100%`），带透视。
   - 也可以整体平移、绕底边中点做小于 3° 的摆动。
   - 禁止：非等比缩放、拉伸、网格变形、液化、骨骼、局部形变。
2. **弹出：** 从 90°（平躺）转到 0°（直立），用时 0.35–0.45 s。
   - 缓动用 `Easing.out(Easing.back(1.4–1.7))`，最多过冲到 −6°（略微后仰），再回到 0°。
   - 不允许通过放大来表现过冲。
3. **收回：** 从 0° 转到 90°，用时 0.28–0.35 s，缓动用 `Easing.in(Easing.cubic)`。
   - 立牌必须在翻页开始前完全收平。
   - 同一个角色换姿势时，先让旧立牌完全收平，再弹出新立牌，同一角色不能同时出现两个。
4. **层级（遮挡）：** 按立牌底边的纵坐标从后往前排列，底边越靠下的越靠前；手持道具排在持有人前面。
   - 立牌落在背景上的接触影也按同样的层级处理。

## 3. 厚度、阴影与光

1. **纸厚：** 立牌底边和侧边有 3–4 px 的纸芯边，颜色取立牌白边色，再压暗 12%。
   - 卡片越倾斜，纸芯边越明显；直立时几乎看不见。
2. **投影：** 两种阴影都随折起角度变化。
   - 接触影：底边一条柔和的椭圆，不透明度约 0.35。
   - 投射影：立牌向后上方投到背景上，模糊半径随立起高度从 4 px 增加到 22 px，不透明度 0.25–0.4。
   - 光源方向全片统一：左上方暖光。
3. **折起过程中的明暗：** 卡片越接近平躺，越暗，最多压暗 25%；直立时就是原画亮度，不能改变原画色彩。
4. **翻页：** 实体纸页以顶边为铰链，从约 88° 翻落到 0°，用时 0.6–0.8 s。
   - 纸页有白色纸边、背面阴影，在下一页上投下渐变阴影；书脊处有装订阴影。
   - 不能做成整个画面旋转，也不能用溶解代替翻页。
5. **氛围光效：**
   - 只能叠加在原画之上：屏幕混合光斑、雪、色调；
   - 色调强度不超过 15%，以免改变原画观感。

## 4. 时间轴：歌词与节拍

1. **音频：** 原 DJ 版 59.04 s，原样使用，不变速、不剪切。
   - 成片封装沿用已验证的 `mux.sh`（bt709、−14 LUFS、AAC），保证 iPhone 播放。
2. **时间单位：** 所有动作都写在 `timeline.ts` 里，用歌词锚点或拍号表示，不在组件里写死秒数。
   - 一拍 `BEAT = 0.418 s`（143.5 BPM），第一拍对齐实测鼓点。
   - 歌词的 15 句时间保持不变，例如 `[1.56–4.62]`……`[48.56–53.20]`。
   - 写法示例：`at: lyric(7).start + beats(1)`，或 `at: beat(64)`。
3. **触发规则：**
   - 立牌弹出落在拍点上；
   - 翻页的落地时刻（θ=0）落在小节第一拍上；
   - 情绪转折（如「惊讶发呆」）落在歌词句首后的第一个拍点上。
4. **字幕：** 按你的要求，不烧录歌词字幕。
   - 画面文字只允许：
     - 封面自带的文字；
     - 地图上的「济南」「泰安」；
     - 结尾的「我们的故事，未来再续……」；
     - 两个日期（2025.11.15 表白、2026.11.15 一周年）。两个日期绝不混用。

## 5. 素材标准（高清透明 PNG）

1. **格式：** 不预乘的 RGBA PNG，每张一个元素。
   - 显示尺寸以 1920 宽画面计。
   - 素材边长要至少达到显示尺寸的 1.5 倍；背景要至少 1920×1080。
2. **抠图质量：**
   - 边缘沿纸雕自身的白色描边走，不能有底色晕边、锯齿、残留邻近碎片，也不能漏掉发丝或配件；
   - 立牌底边必须是平直的铰链边；
   - 「!!」、情绪线等符号要么连在立牌上，要么单独成件。
   - 只要抠不干净，就不用。我会列出缺失项请你补图，不用粗糙抠图顶替。
3. **清单 `assets.json`：** 每个素材登记以下信息。资源进入渲染前，用脚本检查尺寸、alpha 边缘和缺失项。
   - 文件名和来源（哪张原画或素材表、md5）；
   - 铰链边的 y 坐标；
   - 默认显示高度；
   - 是否允许镜像（有文字的不允许）。
4. **已确认的原画：**
   - 已确认的封面（src md5 `37fe1e0…`）、内页和各幕原画，只能整体使用，或按原画自带的 alpha 取件；
   - 不改色、不重绘、不拆分封面。
   - 封面只能整张做刚体翻开。

## 6. 质检清单（每次出片）

- [ ] 1920×1080、24 fps、H.264 High yuv420p + AAC，时长与音频一致（59.04 s 或指定片段）
- [ ] 冻结检测：没有 ≥ 1.0 s 的静止段；黑场检测：没有意外黑场
- [ ] 抽帧检查：每一页的画面都是完整页面，没有缩放或平移
- [ ] 同一角色没有同时出现两个；翻页前所有立牌都已收平
- [ ] 没有新增文字；两个日期没有混用
- [ ] 响度 −14 LUFS ±0.5

## v1.1 修订（学校门口页实测后）

**一、直立清晰度**
- 立牌素材先按屏幕实际尺寸用 Lanczos 预缩放（`scripts/prescale.py`），再放在整数像素坐标上。
- 立牌直立且静止时，不加任何 CSS transform。
- 实测与源图合成相比，平均差 0.9/255。

**二、alpha 精确贴合描边**
- 素材表上的贴纸都自带淡紫色投影，必须先用 `scripts/recut_stands.py` 把 alpha 切到模切描边上。
- 否则新加的投影会和原图自带的投影叠在一起。

**三、立牌参数**
- 立起用时 0.42 s，缓动 `Easing.out(Easing.back(1.25))`。
- 收回用时 0.30 s，缓动 `Easing.in(Easing.cubic)`。
- 收回时立牌全程不透明，不用淡出：纸张半透明会像鬼影。

**四、翻页参数**
- 透视 4224 px，视点 y = 324。
- 新页从观众一侧落下（rotateX 为正），用时 0.75 s，在拍点上落定。
- 透视距离太短时，新页会提前盖满全屏，不能用。

**五、渲染脚本**
- 渲染前必须先删除旧的输出文件（`npm run gate` 已经这样做）。
- 否则输出文件可能没有被覆盖，状态显示为「○」，接下来的质检就会对着旧文件进行。
