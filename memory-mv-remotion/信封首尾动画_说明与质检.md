# 信封开场与结尾动画（无声）

**交付文件**
- `opening_envelope.mp4`
- `ending_envelope.mp4`

**规格（ffprobe 实测）**
- 两个文件都是 1920×1080，16:9，24 fps，H.264 High yuv420p。
- 每段 6.75 s（162 帧），只有视频轨，没有音频轨。
- 没有字幕，也没有新增文字。画面里的文字只有封面和内页原画自带的内容。

## 素材：同一信封、同一贺卡、同一背景
| 图层 | 来源 |
|---|---|
| 背景 | memory-mv-book/up/bg_lace.png（与正片开场相同的粉紫蕾丝水彩背景） |
| 信封内衬（格纹） | 派生自你的打开状态信封 memory-mv-book/cut/env_open.png |
| 信封前袋（侧折和底折） | 同上 |
| 翻盖内面 | 同上：原翻盖本身 |
| 翻盖外面 | 同上：信封自己的底折纸面，上下翻转后按翻盖轮廓裁出，所以翻盖的两面形状完全一致 |
| 蝴蝶结和爱心封蜡 | 派生自你的闭合状态信封 memory-mv-book/cut/env_closed.png。沿画好的丝带描边抠出，去掉了画在纸上的丝带阴影。保留了两翼、封蜡和两条内侧尾带；外侧两条一直延伸到信封角的长丝带属于那个信封的造型，没有使用 |
| 贺卡封面 | 定稿封面 memory-mv-anniv/obj/cover_obj.png，整张使用 |
| 贺卡内页 | memory-mv-card/layers/inner_page.png，加上它的 4 个立体件（摩托头盔、情侣、日期铭牌、双猫）叠合而成。与你发来的内页图平均差约 6/255，只来自重采样 |

所有派生图层都由 `scripts/build_envelope.py` 生成，只复制原画像素，没有重绘。

## 动作（开场）
| 时间 (s) | 动作 |
|---|---|
| 0–0.4 | 画面从暗处淡入：背景加上中央合着的信封 |
| 1.05–1.9 | 爱心封蜡轻轻抬起，蝴蝶结连同封蜡一起向上解下、淡去 |
| 1.85–2.7 | 翻盖作为一张刚性纸片，沿上方折线翻开 180°。外面转过去后，露出格纹内面 |
| 2.6–3.55 | 贺卡夹在内衬和前袋之间，平稳地向上抽出 |
| 3.5–4.5 | 信封向下、向后退去并淡出；完整贺卡来到画面中央并铺满画面 |
| 4.5–4.7 | 内页出现在封面下方 |
| 4.8–6.0 | 封面作为整张硬卡，沿左侧折线翻开，露出完整内页 |
| 6.0–6.75 | 停在完整内页上，方便衔接正片 |

**结尾**：与开场是同一场景逐帧倒放。
- 从完整内页开始；
- 封面合上；
- 贺卡放回信封；
- 翻盖向下折合；
- 蝴蝶结和封蜡回到原位；
- 闭合后静止约 0.65 s，再淡出。

## 检查结果
- **镜头**：固定。没有局部放大、平移或 Ken Burns。画面整体从不翻转，动的只有信封、翻盖、蝴蝶结和贺卡这些独立对象。
- **封面**：完整一张，只做刚体旋转，没有撕裂、拆分、卷曲或液化。翻过 90° 之后显示的是素色卡背，不会出现镜像的正面。
- **阴影**：只有轻微的接触影和翻页影，没有厚重的悬浮阴影。
- **逐帧差分**：两段都没有孤立突变，没有跳帧和闪白。开场第 0 帧和结尾最后一帧是淡入淡出的暗场。
- **翻盖**：两面是同一个轮廓，翻转过程中是同一张刚性纸片，不是两张图硬切换。

## 一处说明
贺卡从信封里出来后来到画面前方并铺满画面，这是贺卡这个物体在移动，不是镜头放大。这是为了衔接正片里铺满画面的内页。
