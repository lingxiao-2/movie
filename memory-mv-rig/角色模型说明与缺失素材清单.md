# 情侣 2D 拆件角色模型 · 说明与缺失素材清单

## 方法（严格刚性，无任何网格形变）
- 设定图 1448×1086 → Real-ESRGAN 动漫模型 ×4 放大 → 按实测坐标逐件裁切 → 以纸张底色距离抠图，去掉贴纸白边，保留原水彩纹理和描边 → `parts/*.png`（81 个）。
- 部件只做三种操作：**平移、旋转、整体缩放**。斜放的手臂件做了一次整体旋转摆正（`*_v.png`），像素没有被拉伸。
- 骨骼 `js/puppet.js`（Canvas 2D 层级变换）：髋 → 躯干 → 颈（头）→ 前发/后发/眼镜；左右肩 → 肘 → 腕（手）；左右髋 → 膝 → 踝（鞋）。关节数据导出在 `parts/male_rig.json`。
- 手型可替换（`alt`：自然垂手 ↔ 张开的手），眨眼用眼皮贴片（用肤色盖住眼睛，再叠上设定图里的「笑眼」线条），不改动脸部。
- 整个角色外加一圈纸偶白边描边，与设定图的贴纸风格一致。

## 男主 5 秒测试（test/男主动作测试_5s.mp4）
0–1 s 站立呼吸 → 1 s 眨眼 → 1.3–1.8 s 抬头 → 1.8–2.45 s 右臂先下沉预备再抬起、换成张开的手 → 2.45–3.75 s 挥手（前臂和手腕摆动） → 3.75–4.6 s 放下、换回原手型、低头恢复 → 4.6 s 再眨眼。
片段无音乐（静音音轨），1920×1080，24fps，无黑帧。

## 已知局限（如实说明）
1. **肩关节**：设定图的上臂是独立的「胶囊」皮肤件，T 恤袖子画在躯干上。手臂抬起时，上臂从固定的袖口下面伸出，袖子本身不会跟着抬起。近看能看出是纸偶关节，这是剪纸动画的正常效果。
2. **男主手掌**只有两种可用于挥手：张开、自然垂下。握拳和抓握件很小（约 100 px），只适合远景。
3. **眨眼**是「肤色眼皮 + 笑眼线条」的合成，不是设定图原画的闭眼。距离近时略显平。
4. **男主腿**：设定图里大腿件是深色短裤腿，被下装件挡住；目前只做了站立姿势，没有测试走路。

## 缺失 / 需要修补的素材
| 部件 | 问题 | 需要的补充 |
|---|---|---|
| 女主白色猫咪 T 恤、白色袖子件、白色头盔 | 颜色接近纸张底色，自动抠图在白色区域留下缺口（见 preview/女主与道具部件一览.jpg） | 请提供**透明背景 PNG**，或把这三件放在深色/纯绿色背景上的设定图 |
| 男主侧面、背面身体 | 设定图只有正面身体和背面头发 | 侧身、背身躯干各一张（用于第三幕骑车、第八幕背影走路） |
| 「手臂抬起时的袖子」 | 抬臂时需要随上臂转动的袖子件 | 男女主各一个独立短袖袖筒（与上臂分开） |
| 闭眼原画 | 当前用笑眼线条合成 | 男女主各一组「正常闭眼」眼睛件 |
| 递花 / 接花手型 | 男主「捧花」手件是双手 + 花束一体，女主有「捧花」 | 男主「单手递出花束」侧向手件；女主「双手伸出准备接」手件 |
| 女主手臂件 | 设定图里的上臂/前臂是斜放、偏短的胶囊 | 可用，女主绑定时再验证比例 |
| 走路 | 只有站立的腿和鞋 | 侧面腿 + 鞋（各 2–3 个步态），用于第八幕 |
