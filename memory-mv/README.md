# 把回忆拼好给你 · DJ 版 — 情侣纸艺回忆 MV

1080×1920, 24 fps, H.264/AAC, 59.04 s. Paper pop-up book style (Lemo-Opuscar), drawn in Canvas 2D.

- `TREATMENT.md` — structure, lyric timing table, shot list
- `model_sheet.jpg` — character model sheet (same code as the film)
- `把回忆拼好给你.srt` — Chinese lyric subtitles
- `build.sh` — rebuilds the film; needs `assets/song.mp3` and `assets/ref/{him1,him2,her1,her2,moto}.png` (not in git)
- `js/` — `chars.js` (the two characters), `moto.js` (the red motorcycle), `art.js` (props, backdrops),
  `engine.js` (2.5D book engine), `scenes.js` (timeline), `main.js` (render loop)
