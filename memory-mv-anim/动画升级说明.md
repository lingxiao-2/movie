# 《把回忆拼好给你》动画升级版 · 技能清单与实现说明

## 一、调研与选型（实际检查过的方案）

| 方案 | 结论 | 原因 |
|---|---|---|
| Anthropic 插件目录：Remotion 技能包、animation-studio、Tweenkit、Sticklore | 未安装 | Remotion/Tweenkit 是网页/React 动态图形，不能让位图插画里的人物手臂弯曲；animation-studio/Sticklore 用代码重新画人物，会替换你的画风。lemo-opuscar 已有同类渲染管线 |
| GitHub：rossark-motion-skill、oil-motion、sprite-gen | 未安装 | SVG/网页动效、游戏精灵图生成，与「让现有插画中的人物动起来」不匹配 |
| facebookresearch/AnimatedDrawings（MIT） | 借用其核心方法，未安装本体 | 需要完整站立人形 + 纯色背景 + Docker 姿态识别服务；你的插画多为半身特写、复杂背景 |
| Blender + blender-skills | 未安装 | 体积大，可用的快速渲染器需要 GPU/OpenGL |
| Live2D / Spine / Rive 编辑器 | 未使用 | 需要图形界面或付费授权 |
| Kling AI 插件（上一轮已安装） | **未使用** | 按积分计费且需要你在浏览器授权，违反「不用付费 API」的要求 |

## 三、实现方法（tools/rig.py + js/rig.js）

1. **分层**：每幕按人物/道具拆成 2–3 个图层（如第五幕：礼物层＝花束+围巾+男主的手和袖子；男主层；女主层）。被前景挡住的部分用该图层自身的颜色补全，移动时不会露洞。
2. **网格**：每个图层自动生成约 800–1,300 个顶点的三角网格。
3. **骨骼组**：头部、手+道具、头发、身体等区域作为刚性「骨骼」，各有旋转支点；关键帧（位移、旋转角）用缓入缓出插值，带预备动作、过冲、停顿；呼吸、走路颠簸、发丝摆动用周期运动。
4. **ARAP 求解**：固定身体下缘等「钉住」区域，其余顶点由 libigl ARAP 每帧求解——脸部和道具保持不变形，手臂、袖子、脖子、头发自然弯曲拉伸。
5. **渲染**：浏览器逐帧把每个三角形用精确仿射映射贴到新位置（lemo-opuscar 渲染管线），再叠加原有的镜头运动、雪花/花瓣/海面/烟花、字幕和调色。
6. **眨眼**：闭眼贴片烘焙进人物图层贴图，随网格一起运动。

## 五、无法可靠实现的部分（如实说明）

- **新姿势需要新画面**：每幕只有一张插画，没有手臂伸直、站起来、转身等另外的姿势。因此：
  - 第二幕「站起」没有做，只做了抬头和举起头盔；
  - 第五幕女主没有真正伸手握住花束（她的手原本捂着嘴，手下面的嘴部并不存在，移开就会露出空白），改为身体前倾、双手伸向花束；
  - 第八幕两人是原地的步行起伏，没有真正走向远处（走远需要腿部的走路循环画面）；
  - 表情不变（委屈变柔和需要另画表情）。
- **第三幕车轮**是前轮下半圈的旋转模糊，不是逐帧转动的辐条（前叉和排气管压在车轮上）。
- **第六幕**原拼贴里没有牵手的画面，所以日常部分没有牵手镜头（牵手在第八幕）。
- 动作幅度刻意控制在不撕裂画面、不扭曲五官的范围内。

如果需要更大的动作（真正伸手接花、站起、走远），有两条路：
1. 你提供同画风的补充姿势图（如「女主伸手接花」「男主站起」），可以直接接入现有骨骼和时间轴；
2. 使用已安装的 Kling 图生视频（付费积分，需要你在 /mcp 授权），这次按你的要求没有使用。
