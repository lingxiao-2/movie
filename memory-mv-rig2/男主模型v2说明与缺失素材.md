# 男主可动模型 v2 · 说明与缺失素材

## 组装方案（全部刚性，无形变）
- **身体主体 = 设定图左侧「完整角色·正面」原画**（头部、眼镜、头发、T 恤身体、长裤、鞋全部原样），保证比例与示例一致。
  - 袖子沿 T 恤上画好的肩缝线切下；双手插兜原画已移除，两侧裤兜用周围裤料颜色补画，并补上与原画一致的深色描边。
  - 头部单独成层，可绕脖子做小幅抬头（平移 + 2° 旋转），脖子留在身体层，不会露缝。
- **手臂 = 设定图「左/右上臂（含袖口）」+「前臂」+ 替换手型**。
  - 袖子和上臂是同一部件，抬手时袖子跟着手臂转动。
  - 前臂部件在手腕处裁掉原有的拳头，接上「放松」（垂手）或「张开」（挥手）手型。
- 层级：身体 → 头 → 上臂（含袖） → 前臂 → 手；关节：肩、肘、腕、颈。
- 被裁掉的部位只用于删除，没有任何像素被拉伸或液化。
- 未使用：设定图的「上半身」部件（比示例的 T 恤短约三分之一，会改变比例），以及「骨盆/大腿/小腿/鞋」部件（示例的整条长裤效果更好）。

## 静态检查（男主静态组装检查.jpg）
自然站姿、单手抬起（挥手）、双手自然下垂：头身比例一致，四肢连接完整，抬手时袖子随动，无缺口。

## 动画测试（男主动作测试v2_5s.mp4，1920×1080，24fps）
0–0.9 s 站立（呼吸起伏）→ 0.9–1.45 s 抬头 → 1.55–2.35 s 手臂先轻微下沉（预备），再抬到身侧、手肘弯起 → 2.4–3.85 s 挥手（前臂和手腕摆动） → 3.85–4.6 s 放下手臂、低头回正。镜头为腰部以上中景，缓慢推近。

## 已知局限
1. 手肘处是两个部件叠接，手肘弯曲角度大时能看出一个小转角，属于剪纸动画的正常效果。
2. 抬起的手臂是正面视角向外侧举起；举过头顶或伸向镜头这类透视动作，需要另外的素材。
3. 眨眼还没有接入：他的眼睛在眼镜框里面，需要「戴眼镜状态的闭眼」贴片才能干净地替换（设定图里的闭眼没有眼镜框）。
