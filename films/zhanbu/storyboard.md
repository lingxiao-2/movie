# 《为什么占卜让你觉得准？》分镜表

外观 C 夜曲（黑底 · 暖白字 · 香槟金细线），16:9，1920×1080，30fps，无旁白。规范见 `docs/01-视觉规范.md`，事实见 `docs/02-知识框架.md`。

- **一句话论点**：随机本来就会制造巧合；大脑在巧合里看出图案，只记住应验的，再编成关于自己的故事——这就是"准"。
- **全片的形象**：一枚铜钱，和被香槟金细线连起来的东西。
- **那把尺子**：金色占多少。金 = 大脑选中的；灰 = 同样存在、被略过的。
- **同一个画面**：序章第 3 镜的"乙排铜钱"，在终章回来，金线把它的连号连成一个"卦"。
- **"哦——"的那一下**：序章第 5 镜。一万排铜钱停住，灰的退下去，满屏只剩金色的"扎堆"：随机看起来就像有规律。

**自查**

- 遮住字幕只读第 4 列：两排铜钱 → 一排在不停换面 → 另一排连了 5 个 → 一万排都有连号 → 只剩金色的连号 → 片名。看得出在讲"随机会扎堆"。
- 字幕里的名词屏上都有：铜钱、两排、20 次、甲、乙、5 个正面、77%、连续 4 次、扎堆。
- 6 镜里 1 镜停住（第 5 镜）+ 片名卡，约占五分之一到三分之一。
- 一个场景撑了 3 句：第 1–3 镜都是这两排铜钱，每句只改一处（落下 / 甲排刻度 / 乙排金线）。
- 屏上的数：15（甲排换面数，数得出）、5（乙排连号，数得出）、77%（模拟结果，精确值 76.8%）。
