# 《为什么占卜让你觉得准？》视觉规范

外观：**C 夜曲**（`vibe-knowledge-film` 的 night 底与版式）。按你的要求收成一套更窄的色板：**黑底、暖白字、香槟金细线**。
夜曲默认的冰蓝、玫红、紫色**全片不用**；不混用寓言（B）或其他风格家族。

## 1. 底

| 项 | 值 | 说明 |
|---|---|---|
| 底色 | `#010104` | 夜曲原底，接近纯黑 |
| 中央光池 | `#15110B`，透明度 0.62 × 0.55 | 把夜曲的深蓝换成极暗的暖褐，几乎看不出，只让中心不死黑 |
| 星点 | 关闭 | 本片的"星"在第 2 章是讲解对象（随机散点 → 被连成星座），不当装饰用 |
| 暗角 | 0.5 | 夜曲原值 |
| 辉光 | 0.85 | 比夜曲默认的 1 略低：铜钱是实物，放在辉光层下面画 |
| 颗粒 | 0.05 | 引擎默认 |

## 2. 色板与含义（全片不破例）

| 名称 | 色值 | 只用在 |
|---|---|---|
| 暖白 | `#F4EEE3` | 主体大字、片名实字 |
| 字幕暖白 | `#E6DFD2` | 中文字幕 |
| 暖灰 | `#8D867B` | 英文字幕、双语小标 |
| 暗灰 | `#5A554D` | "没被注意到的"：被忽略的铜钱、没应验的预言、褪掉的记忆 |
| **香槟金** | `#E3CB97` | **大脑挑出来的东西**：被连起来的图案、被记住的"应验"、被编进故事的那一条线 |
| 暗金 | `#A88F64` | 金色的弱化态：刻度、细线的底、副题 |
| 铜钱 | 青铜 `#3A2A17 → #8A6A3E → #CDB07A`（高光） | 只给铜钱这一件实物；不发光 |

**规则：金色 = "你的大脑选中了它"。** 全片一切金色的东西，都是被注意、被连线、被记住、被赋予意义的那部分；
灰色是同样存在、却被略过的那部分。观众看完片子，会自己发现"金色总是少数"。

## 3. 字

| 元素 | 字体 | 字号 / 字距 | 位置 |
|---|---|---|---|
| 中文字幕 | 思源宋体 Regular（`serifr`） | 41 / 0.12em | 中线 y=939（87%） |
| 英文字幕 | Lora Italic | 29 | y=995（92%），晚 0.18s 淡入 |
| 主体大字 / 大数字 | 思源宋体 Light（`serifl`）/ Cormorant | 92–150 | 中线 y≈437 |
| 双语小标 | 宋体 22 + 等宽大写 15（字距 5px） | 暖灰 | 贴着东西，一镜最多一条 |
| 章节标 | 等宽 15 编号 + 宋体 22 一个字 + 等宽 13 英文 | 三成亮度 | 左上 x=101，y=88，下面 250px 金色细线 |
| 片名 | 宋体 Light 112，字距 26 | 由金色点阵聚成，再落成暖白实字 | 中线 y=438 |
| 副题 | 宋体 Medium 36，字距 18，暗金 | | 片名下 150px |

字幕一行不换行、不加底板、整行 0.55s 淡入；一句最多染一处金色，三句里至少两句不染。

## 4. 线与光

- **香槟金细线**：1–1.3px，四到七成亮度；需要强调时加一圈 6–10px 的淡辉光。用来连图案、画刻度、给一段"连号"划线。
- 刻度：细线两端和每隔一格各一道 5–8px 的短竖线，像一把尺子。
- 光点母题（夜曲原有）：只在片名卡出现，改成金色核 + 暖白晕。

## 5. 实物画法：铜钱

全片的主道具是**方孔圆钱**（掷钱起卦用的铜钱）。画在辉光层之下（`fr.look.under`），不吃辉光。

- 外圆 + 宽边郭 + 中央方孔；径向渐变出体积，左上一道高光，右下压暗。
- **正面（字面）**：亮青铜，方孔四周四个字"太 平 通 宝"（借用北宋常见钱文的四个字，钱的造型是代码现画的，不参照任何实物照片）。
- **背面**：暗青铜，只有内外郭，没有字。
- 落地动作：从上方落下，绕水平轴翻转（纵向压扁 → 展开），最后一下弹跳落定。

## 6. 运动与节奏

- 字幕出现后 0.3 秒内屏上有动作；任何一刻只有一个主体在动。
- 场景之间不硬切：相邻两段时间窗重叠 0.5 秒各自淡入淡出；或者让上一幕的东西变成下一幕的东西（大铜钱缩成小铜钱墙的第一行）。
- 纵向 80%–95% 只给字幕，装置最低点不低于 y=840。
- 每 20–30 秒一段无字幕的纯画面。

## 7. 声音（全部合成，`engine/audio.py`）

铜钱落地一声 `tick`（音高随机微调）；揭晓一记 `chord`；模拟加速时 `rise`；片名前 `hush` 静一拍，进片名 `bloom`。整体约 −18 LUFS，很安静。

## 8. 不做的事

- 不用冰蓝、玫红、紫；不出现第二套外观。
- 不搬 `examples/` 或其他创作者成片里的画面、素材、代码；铜钱、模拟、片名卡都为本片现写。
- 不加水印、不加署名。
